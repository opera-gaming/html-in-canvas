# Effects

Live, still-usable HTML panels drawn into WebGL2 through game shaders, using HTML-in-Canvas.

- `/fire/` Slider on Fire: the slider sets how hard the panel burns.
- `/teleport/` Teleport: a switch beams the settings panel out and back in.
- `/endgame/` Dust to Dust: a switch turns the panel to stone and blows it away.
- `/electric/` High Voltage: the voltage slider charges the panel with electricity.
- `/transitions/` Page Transitions: all 56 transitions of Opera's GameMaker transition prefab between two live pages.
- `/post/` Post-Processing: motion blur, bloom, screen fringe and vignette over a live page.
- `/frost/` Frosty Checkboxes: ticked rows frost over.

Shared WebGL and capture code lives in `../kit` (imported as `@kit/…`). `src/transitions/generated.ts` is generated by
`node tools/import-transitions.mjs <prefab-transition>/transitions <gl-transitions>`, which also records each
transition's gl-transitions author and licence.

## Run

Needs a Chromium with `chrome://flags/#canvas-draw-element` enabled, and WebGL2 with `EXT_color_buffer_float`.

    npm install
    npm run dev

Then open http://localhost:5181.
