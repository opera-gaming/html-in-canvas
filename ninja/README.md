# HTML Ninja

A Fruit Ninja-style game where you slice flying HTML elements (buttons, cookie banners, toggles, a CAPTCHA, a live
clock) instead of fruit. Don't slice the burning molotov.

## Controls

Swipe fast with the mouse, pen or finger to slice. Slice the menu to start or retry. The button in the corner toggles
the music.

## Run

Needs Opera GX or another recent Chromium with `opera://flags/#canvas-draw-element` (or
`chrome://flags/#canvas-draw-element`) enabled, plus WebGL2 with `EXT_color_buffer_float`.

    npm install
    npm run dev

Open http://localhost:5182.
